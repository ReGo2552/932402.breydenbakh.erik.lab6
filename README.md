# 932402.breydenbakh.erik.lab6

Лабораторная работа №6 по курсу «Веб-технологии», ТГУ, группа 932402.
Вариант 2 - «Часы и часовые пояса».

## Возможности

- `GET /` - главная страница с текущим временем (обновляется раз в секунду через `/api/time`).
- `GET /about` - страница о приложении.
- `GET /api/time` - JSON с текущим временем и часовым поясом сервера.
  - `?format=12` - переключает 12-часовой формат (по умолчанию - 24-часовой).
- Статика (CSS/JS/иконки/manifest) отдаётся через `express.static`.
- Несуществующие маршруты → `404 { "error": "Not found" }`.
- PWA: `manifest.json` + service worker - приложение можно установить и открыть офлайн
  (последнее полученное время кешируется и показывается вместо ошибки сети).

## Как запустить

```bash
npm install
node server.js
```

Сервер стартует на порту `3000` (или `$PORT`, если задана переменная окружения),
в консоли будет `Server started on port 3000`. Открыть `http://localhost:3000/`.

Проверка офлайн-режима: DevTools → Network → Offline → обновить страницу - приложение
должно открыться из кеша service worker'а с последним известным временем.

## Стек
